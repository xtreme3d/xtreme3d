Lesson 1. Xtreme3D Basics

So, what is Xtreme3D?

First and foremost, it's a stage. A stage where "actors" (objects) play. An object is the fundamental concept of the Xtreme3D API. It's not the same as a GameMaker object. Xtreme3D objects are created and managed exclusively via code. 3D models, primitives, special effects, the background sky, images, and text on-screen - all are objects. Objects of all types are controlled, in most cases, by the same functions that set their position, rotation, scale, and other properties.

One such feature is hierarchy. Any object can have one or more subordinate objects - "children." In this case, the child itself becomes their "parent" (hereinafter, without quotation marks). Descendants, in turn, can have their own descendants, and so on. The entire scene is built on this principle. What are the advantages of this? For example, if you disable an object (making it invisible on screen), all of its descendants (and, consequently, the descendants of its descendants) will also be disabled by default. However, you can enable any descendant without affecting the parent. This "inheritance" is the most obvious feature of the hierarchy. But that's just the tip of the iceberg. An object's descendants can inherit not only its state but also a number of other characteristics. For example, an object becomes bound to its parent - where the parent goes, so does the descendant. The descendant itself can move any distance, but only relative to its parent's location. To make it easier to understand, imagine a steamship: passengers can move freely on the deck or stand still, but they all essentially move with the ship itself.

Thus, we gradually come to movement. In computer graphics, any translation, rotation, and scaling are united under the general term "transformation." Transformation in Xtreme3D is performed along three mutually perpendicular coordinate axes: X, Y, and Z. The X axis is directed to the right, the Y axis is upward, and the Z axis is "depth." This coordinate system is called the Cartesian coordinate system, named after the French mathematician Rene Descartes. The location of any point in the coordinate system is defined by its three projections onto the axes. For example, the points (-1,0,-1), (-1,0,1), (1,0,1), and (1,0,-1) form a 2x2 square lying on the XY plane. Thus, any Xtreme3D object has three coordinates describing its position in space. Typically, this point coincides with the object's own center. The object's position in space can be conveyed relative to the absolute origin of the scene (0,0,0) or relative to the coordinates of its parent, if any. In the second case, we are talking about the so-called local coordinates of the object, in which the point (0,0,0) of the child always corresponds to the position of the parent.

An object is moved using a vector. A vector is a segment directed from the point (0,0,0), in local or absolute coordinates, to any other arbitrary point in the same coordinates and is described by the coordinates of that point. An object can be moved arbitrarily by any distance in the direction indicated by the specified vector. For example, the vector (0,10,0) moves the object ten units up.

However, since it is not always convenient to manually calculate a vector for the desired direction of movement, Euler angles (named after Leonhard Euler, a Swiss scientist) are used. They specify the angles of rotation of the object around its local axes X, Y, and Z. The perpendicular axis is taken as the zero angle. Rotation around the X-axis is called Pitch, around the Y-axis is called Turn, and around the Z-axis is called Roll. It's easy to guess that, for example, an angle of (90,0,0) tilts the object backward by 90 degrees.

The resulting transformation defines the object's direction (Direction), which is also described by a unit vector. A unit vector differs from a standard vector in that its length is equal to one (for a vector describing direction, length is irrelevant). For example, the direction vector (0,1,0) corresponds to the angle (90,0,0).

Thus, we obtain another characteristic of the object—its direction.

An object's movement in its direction is accomplished by multiplying the direction vector by the distance of movement:

(0, 0, 1) * 10 = (0, 0, 10) (1, -1, 1) * 10 = (10, -10, 10)

As a result, we obtain the object's new coordinates (relative to the previous ones).

In addition to the Direction vector, an object also has automatically calculated Up and Left vectors, pointing up and left, respectively, relative to the direction. These three mutually perpendicular vectors form a new coordinate system (Left = X, Up = Y, Direction = Z), which is inherited by all descendants of the object. This coordinate system becomes local for each descendant, and all its transformations are defined within it. This means that if we create a descendant for an object and move it a certain distance to the side, then when the parent rotates, the descendant will rotate around it, just as the Earth rotates around the Sun! This is an incredibly useful property of hierarchy. As you'll soon see, it's used at virtually every step in Xtreme3D.

The third transformation remaining is scaling. It changes the object's size along three axes (width, height, and length). Scaling can be relative to the current scale value or absolutely (to specify a specific size in absolute units). The coordinate system inherited by the object's descendants is also scaled. That is, the child will not only be scaled down, but also brought closer to the parent, as if we were scaling down an entire system of objects. Strictly speaking, parent and child are the object system itself. It can be viewed as a single large object consisting of individual, logically grouped elements.

Thus, all objects in our scene exist according to certain mathematical laws. Once you understand these laws, learning Xtreme3D will be a breeze.
